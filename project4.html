Web-Based Physical Activity Classification System Using Random Forest

KategoriMachine Learning
PeranMachine Learning Developer (Random Forest Model Development)
Tahun2026

Project Overview

This project focuses on developing a web-based physical activity classification system using the Random Forest algorithm. The system analyzes user health and lifestyle data, including sleep duration, BMI category, heart rate, and daily steps, to classify physical activity levels into predefined categories. The machine learning model is integrated into a web application, allowing users to input data and receive instant predictions through an interactive interface.

My Contribution

In this project, I developed a web-based machine learning system for physical activity classification using the Random Forest algorithm. My work involved dataset preparation, data preprocessing, feature engineering, model training and evaluation, as well as integrating the trained model into a Flask web application. Additionally, I designed the prediction interface to provide users with an intuitive and seamless experience when interacting with the system.

Challanges & Solutions

One of the primary challenges was improving model performance while maintaining generalization across different activity categories. The dataset required preprocessing, feature selection, and validation to ensure reliable predictions. Data preprocessing and feature engineering techniques were applied to improve data quality. Hyperparameter tuning and model evaluation were conducted to enhance classification performance before deployment.

Dataset Features

Results
