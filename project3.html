Smart Irrigation and Fertigation System Based on IoT, Web Monitoring, and Venturi Injection

KategoriUI/UX Design & Web App
PeranUI/UX Designer & Developer
Tahun2024

Project Overview

Smart Irrigation and Fertigation System is an IoT-based agricultural monitoring platform designed to help users monitor and control irrigation and nutrient distribution processes remotely. The system integrates environmental sensors, web-based monitoring, and Venturi Injection technology to improve water and fertilizer management efficiency.

My Contribution

My primary role in this project was UI/UX Design. Responsibilities included:
• Designing user interfaces using Figma.
• Creating user flows and navigation structures.
• Designing dashboard layouts for real-time monitoring.
• Developing high-fidelity prototypes.
• Improving usability and user experience across the platform.

Challanges & Solutions

One of the main challenges was organizing multiple sensor readings and control functions within a single interface while maintaining clarity and ease of use. A dashboard-centered layout with clear visual hierarchy, grouped information cards, and intuitive navigation was implemented to improve readability and user efficiency.

Key Features

• Real-time sensor monitoring.
• Irrigation control.
• Fertigation management.
• Environmental monitoring dashboard.
• Responsive user interface.

Problem Statement

Farmers often face challenges in monitoring irrigation and fertigation systems manually. Accessing sensor information and controlling the system can be inefficient without a centralized and user-friendly interface.
